# DSH Session Markdown Export

从会话标题栏下载一份可阅读的 Markdown 轨迹，保留对话、工具调用和压缩摘要，方便归档或复盘。

## 下载当前会话

```sh
dsh plugin --profile desktop add 'github:AsakuraAOI/dsh-session-md-export'
```

支持 **DSH 0.2.1-rc.1 / rc.2**。安装后按管理器提示重启，在会话头部点击新增的下载图标：

- **纯轨迹**：用户消息、助手回复、工具调用与结果。
- **含思考过程**：额外输出日志中保存的思考块。
- **含系统提示与元信息**：额外输出系统消息、标题和命令记录。

导出前会刷新活动会话中已提交的事件。文件名使用最新会话标题，保留中文、空格和 emoji；保存位置由浏览器下载设置决定。

## Markdown 里有什么

用户和助手消息按顺序排版，工具结果放进可折叠区块，压缩摘要和失败信息使用引用块。工具调用保留 JSON 参数，正文中的代码围栏会按需要加长。

每条工具结果默认最多 **4000 字符**。导出选项可调整上限，以及是否包含投递事件；默认不重复输出投递记录。

这是一份文本轨迹。图片和文件附件保留引用链接，需要附件本体时请使用 DSH 官方 ZIP 导出。子会话不在当前导出范围内。

## 已有日志也能离线渲染

```sh
node scripts/render-cli.mjs <session.v4.jsonl.zstd> out.md --reasoning
```

脚本读取本地日志，无需启动 Host。会话内容可能包含项目资料、工具输出或系统提示，分享前请检查所选导出范围。

## 开发入口

`lib/markdown.js` 负责渲染，`index.js` 负责经过认证的导出路由，`client.js` 提供下载菜单。路由直接交给浏览器下载，不返回 Host 文件路径。

```sh
npm test
```

测试覆盖配置默认值、中文文件名和下载流程。许可：MIT。
